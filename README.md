# Antithesis

A Rivals-style 1v1 / 2v2 arena shooter for Roblox. You walk around a third-person lobby and stand on a pad to queue. When the opposite pad fills, a 5-second countdown sends everyone into a first-person match, and the first side to win 5 rounds wins.

The full design is in [`GAME_DESIGN.md`](GAME_DESIGN.md). Everything is code: the lobby, the arenas, the weapon models and the UI are all generated by scripts, so you don't have to build anything in Studio.

## What's in the game
- **Lobby (third person):** a round hub with four arms in a **+** shape.
  - **North: PLAY.** 4× 1v1 and 2× 2v2 pad stations, each with wall boards showing `0/1` (or `0/2`). When both pads of a station are full, a 5-second countdown starts. Stepping off cancels it.
  - **East: COSMETICS SHOP.** Weapon palettes on display stands. Walking in opens the shop.
  - **West: DAILY QUESTS.** 3 random quests a day, each worth 50–150 coins. Walking in opens the quest list, where you claim rewards.
  - **South: FIRING RANGE.** A teleport pad sends you to a separate range room 200 studs away, in first person with your weapons and target dummies. A pad there brings you back.
  - Loadout, Shop and Quests buttons on the left work anywhere in the lobby. Weapons are unlocked from the Loadout menu.
  - Challenge any player by walking up to them and holding **E**.
- **Matches (first person):**
  - 1v1 and 2v2, first to 5 rounds, one life per round. All matches are casual for now.
  - A fresh arena (Fulcrum or Mirrorline) is built for every match and removed afterwards.
  - Your loadout is the one you equipped in the lobby, and it stays locked for the whole match.
  - Rematch from the results screen.
- **11 weapons:**
  - Primaries: Paragon AR, Breaker shotgun, Hornet SMG, Triad burst rifle, Meridian sniper.
  - Secondaries: Ward pistol, Verdict revolver.
  - Melee: Edge knife (backstab for 100).
  - Utility: Glare flash, Veil smoke, Crack frag.
- **Coins:**
  - Earned from matches, daily quests, win streaks, banners, first win of the day, and a 7-day login streak.
  - They unlock weapons (in the Loadout menu) and weapon palettes (in the Cosmetics Shop).
  - Coins are never sold for Robux.
- **Movement:** slide (C / Ctrl), dash (Shift) and crouch.
- **Netcode:** every hit is checked by the server, with lag compensation (200 ms rewind cap), fire-rate and ammo checks, a line-of-sight check, and a movement speed check.
- **Rounds:**
  - Each round lasts 60s (1v1) or 75s (2v2).
  - After that, a 15s Collapse ring shrinks toward the center and damages players outside it.
- **Feedback:**
  - Hit markers, headshot sound, a kill sound that rises in pitch, kill shatter, and directional damage indicators.
  - Banners: FLAWLESS, CLUTCH 1v2, NO-SCOPE, DOUBLE.
  - Enemy outlines and a sniper scope.
- **Also in the lobby:** a weekly wins leaderboard and an FOV setting.
- **Saving:** DataStore, with protection against overwriting real data after a failed load.

## Quick test (no setup)
1. Download **`Antithesis.rbxlx`** from this repo and double-click it to open it in Roblox Studio.
2. Press **Play** and walk around the lobby. You spawn in the center facing the PLAY arm. Shop is to your right, Quests to your left, and the firing range teleport is behind you.
3. To test a duel, open the **Test** tab, set **Clients and Servers** to 2 players, then click **Start**. In one player window, walk onto the cyan pad of a **1v1** station in the PLAY arm. In the other, walk onto the orange pad next to it. The match starts after 5 seconds.

Coins only save after you publish and turn on **Game Settings → Security → Enable Studio Access to API Services**. Until then the game still runs, but progress resets each session.

`Antithesis.rbxlx` is built from `src/` with `rojo build -o Antithesis.rbxlx`. Rebuild it after changing code, or use the live-sync setup below while developing.

## Setup for development (about 10 minutes)
1. Install **Roblox Studio** and **VS Code**.
2. In VS Code, install the **Rojo** extension (by evaera). Open this folder, run **"Rojo: Open menu"**, then click **Install Roblox Studio plugin** and **Start server** for `default.project.json`.
   - CLI alternative: install Rojo 7.4+ and run `rojo serve`.
3. In Studio, create a **Baseplate** place.
4. Go to **Plugins → Rojo → Connect**. The code syncs in. The scripts delete the baseplate and build the map when you press Play.
5. **File → Publish to Roblox**, then set **Game Settings**:
   - **Avatar → Avatar Type: R6.** The place file already sets this, but check it after publishing. R6 gives every player the same hitbox size.
   - **Security → Enable Studio Access to API Services**, so coins save while testing.
6. Test a duel: open the **Test** tab, set **Clients and Servers** to 2 players, then click **Start**. Put one player on each pad of a **1v1** station.

## Controls
| PC | Gamepad | Action |
|---|---|---|
| LMB / RMB | RT / LT | Fire / Aim |
| WASD, Space | Left stick, A | Move, Jump |
| C or Ctrl | B | Crouch / Slide |
| Shift | LB | Dash |
| R | X | Reload |
| G | RB | Throw utility |
| 1 / 2 / 3 | Y (cycle) | Primary / Secondary / Knife |
| M | Select | Loadout menu (lobby only) |

On mobile these are on-screen buttons, and you drag on the screen to aim.

## Tuning and content
- **All numbers** live in `src/shared/Config.luau`: weapon stats, prices, timers, rewards, the quest list and the lobby zones.
- **Arena layouts** are box lists in `src/server/World.luau`. Each layout describes one half of the arena and is mirrored automatically.
- **Sounds** default to built-in engine sounds. Replace them in `Config.Sounds` with `rbxassetid://...` ids from the Creator Store.
- **Robux palette:** create a Game Pass on the Creator Dashboard and put its id in `Config.Palettes.Neon.gamePass`.

## Project layout
```
src/shared   Config, Net (remotes), WeaponModels      -> ReplicatedStorage.Shared
src/server   World, Lobby, Match, Combat, Data, entry   -> ServerScriptService.Server
src/client   Hud, Menus, Weapons, Movement, UI, State -> StarterPlayerScripts.Client
```
